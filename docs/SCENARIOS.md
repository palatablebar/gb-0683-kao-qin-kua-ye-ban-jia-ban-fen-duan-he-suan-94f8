# 夜班反例

18位员工各有10月1日22点进、10月2日06点出。02点至03点休息，实际7小时，前两小时是假日3倍，次日5小时正常1倍，20元时薪合计220元。直接把整个夜班按归属日计假日会错算420元。脏批额外含缺时薪、冲突打卡、BOM、短行、空行与重复表头。

# 停线待命反例（sample_data/stoppage.csv）

同一批夜班叠加四类停线回执：E001 在 23:00-23:30 设备故障、03:00-03:30 停电，均为企业责任，60分钟改判可付待命（STANDBY，20元时薪×1倍=20元），正常作业仍保留360分钟；E002 在 04:00-04:45 设备故障但责任 pending，先按45分钟无薪中断（INTERRUPTION，0元）挂账，回执补录确认责任后整批失效重算；E003 在 05:00-05:30 员工原因停线，不付待命；E999 无对应班次，回执隔离为 NO_SHIFT。若把等待时间直接当正常作业，会把无产出的135分钟错计成假日/正常工时工资。停线分钟守恒要求事件135分钟=待命60+中断75，否则对账不平、禁止封存。
